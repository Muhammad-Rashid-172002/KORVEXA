## Other checks

- **File uploads:** presigned URLs with signed content-type and length, size/type limits, ClamAV scan before download is allowed; production refuses `SCAN_MODE=off`.
- **Open redirects:** `safeNext` restricts post-login redirects to same-site paths.
- **CORS:** locked to `WEB_URL` + `CORS_ORIGINS`, credentials only for those.
- **Account deletion / export:** D-108; export never includes password hashes, tokens or 2FA secrets.
- **Dev data in production:** the API refuses to boot if the database contains `is_seed` rows or `*.glasswork.test` accounts (`packages/db/src/prod-guard.ts`).
